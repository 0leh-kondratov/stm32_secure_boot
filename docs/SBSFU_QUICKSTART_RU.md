# Быстрый старт: X-CUBE-SBSFU на STM32

Пошагово: скачать пакет, найти проект под STM32H7/NUCLEO и запустить на плате.

---

## 1. Скачать X-CUBE-SBSFU

### 1.1 Где скачать

- **Страница пакета:** [st.com/en/embedded-software/x-cube-sbsfu.html](https://www.st.com/en/embedded-software/x-cube-sbsfu.html)
- На странице нажмите **「Get Software」** или **「Download」** (или «Software resources» → последняя версия).
- Для скачивания нужна **учётная запись ST**. Если её нет — зарегистрируйтесь на [st.com](https://www.st.com).

### 1.2 Что скачается

- Файл вида `en.x-cube-sbsfu-vX.X.X.zip` (или `x-cube-sbsfu.zip`). Версия в имени может отличаться.
- После распаковки получите каталог `STM32CubeExpansion_Secure_Boot_SBSFU_VX.X.X` (или похожий) с подпапками:
  - **Projects** — примеры под разные платы и серии (в т.ч. STM32H7);
  - **Middlewares** — Secure Engine, криптобиблиотека и др.;
  - **Documents** — PDF (User Manual, Integration guide).

### 1.3 Куда положить

Рекомендуется рядом с нашим проектом, чтобы не путать с нашим кодом:

```text
/data/projects/
├── stm32_secure_boot/     # наш проект
├── STM32CubeH7/          # уже есть (официальный Cube)
└── STM32CubeExpansion_Secure_Boot_SBSFU_Vx.x.x/   # распакованный X-CUBE-SBSFU
```

Либо в любое удобное место; дальше везде подставьте свой путь к распакованному пакету.

---

## 2. Найти проект под STM32H7 / NUCLEO

После распаковки зайдите в каталог **Projects**:

```bash
cd /path/to/STM32CubeExpansion_Secure_Boot_SBSFU_Vx.x.x/Projects
ls
```

Обычно внутри есть подпапки по сериям и платам, например:

- `STM32H743ZI-Nucleo144/` или `NUCLEO-H743ZI/`
- либо общая папка `STM32H7xx/` с подпапками по платам.

Зайдите в папку, соответствующую **NUCLEO-H743ZI** (или вашей плате). Внутри могут быть:

- **SBSFU_Boot/** — образ загрузчика (Secure Boot);
- **SBSFU_App/** — пример приложения;
- файлы проекта **.ioc** (STM32CubeMX), **.project** (STM32CubeIDE).

Для первого запуска достаточно найти **готовый проект под вашу плату** (NUCLEO-H743ZI).

---

## 3. Собрать и прошить

### Вариант A: STM32CubeIDE (рекомендуется ST)

1. Установите [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html) с st.com.
2. **File → Open Projects from File System** (или Import → Existing Projects) и укажите каталог проекта, например:
   `.../Projects/STM32H743ZI-Nucleo144/SBSFU_Boot`.
3. Соберите проект (Project → Build Project).
4. Подключите NUCLEO по USB, выберите **Run** или **Debug** — прошивка и запуск выполнятся из IDE.
5. Аналогично откройте и соберите **SBSFU_App**, затем прошейте приложение по инструкции из User Manual пакета (часто через Ymodem по UART или отдельным шагом в IDE).

Порядок «сначала Boot, потом App» и способ прошивки App описан в **User Manual (DM00414687 / UM2262)** в комплекте пакета.

### Вариант B: Makefile (если в примере есть Makefile)

В некоторых примерах SBSFU есть Makefile:

```bash
cd /path/to/Projects/STM32H743ZI-Nucleo144/SBSFU_Boot
make
```

После сборки в каталоге появится `.bin` или `.elf`. Прошить можно так:

```bash
st-flash write build/sbsfu_boot.bin 0x08000000
```

(Имя файла и путь `build/` смотрите по факту в вашей версии пакета.)

Затем по документации пакета прошейте приложение (часто в другой адрес, например слот приложения).

### Вариант C: Документация пакета

Точные шаги для вашей платы и конфигурации (single-slot / dual-slot, откуда прошивать App) смотрите в:

- **User Manual** — в папке `Documents` распакованного X-CUBE-SBSFU (DM00414687 или UM2262);
- **Integration guide** (DM00414677).

Там указаны адреса во Flash, порядок прошивки Boot и App и использование Ymodem при необходимости.

---

## 4. Проверка на плате

- После прошивки **SBSFU_Boot** и **SBSFU_App** по инструкции пакета сделайте **Reset**.
- Обычно: зелёный LED при успешном запуске; при включённом UART — сообщения бутлоадера и приложения (параметры порта см. в User Manual).
- Если включён Secure Firmware Update по UART, в логе может быть приглашение к загрузке нового образа по Ymodem.

---

## 5. Связь с нашим проектом

- **Наш проект** ([stm32_secure_boot](../readme.md)) — минимальный бутлоадер со своей подписью (ECDSA) и без обновления по UART; один скрипт `./scripts/flash.sh` собирает и прошивает всё.
- **X-CUBE-SBSFU** — полноценное решение ST: проверка подписи (RSA/ECDSA), обновление по UART, два слота и т.д.; сборка и прошивка по инструкциям пакета (часто через CubeIDE).

Оба варианта можно держать на одной машине: наш код в `stm32_secure_boot`, официальный — в распакованном X-CUBE-SBSFU. Для одной и той же платы NUCLEO-H743ZI при переключении между ними достаточно прошивать соответствующий образ с 0x08000000 (и при необходимости приложение — по инструкции того решения, которое используете).

Если после распаковки у вас нет папки под NUCLEO-H743ZI — откройте **Documents** пакета и проверьте список поддерживаемых плат в User Manual; для части плат может потребоваться перенос примера с другой платы по Integration guide (DM00414677).
